GET /v1/telemetry

Queries simulated network intrusion metrics and server load status flags. Returns current logging coordinates in JSON arrays.

curl https://api.northstar.example.com/v1/telemetry \\
  -H "Authorization: Bearer MOCK_KEY"

POST /v1/deploy

Triggers simulated serverless function deployments. In a real system, this endpoint indexes repository builds and triggers build actions.

curl -X POST https://api.northstar.example.com/v1/deploy \\
  -d '{"branch":"main"}'
