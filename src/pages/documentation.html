2. CSS Variables Layout

Define layout variables inside the stylesheet `:root` element. To apply glassmorphism styles, integrate backdrop-filter and border parameters:

:root {
  --bg-color: #030712;
  --surface-glass: rgba(17, 24, 39, 0.55);
  --border-glow: rgba(255, 255, 255, 0.08);
  --glass-filter: blur(12px) saturate(180%);
}
