# Changelog

All notable changes to the Northstar Studio portfolio system are logged below.

## [1.1.0] - 2026-07-10
### Added
- Created 15 new templates including `Style Guide`, `Design System`, and `Accessibility Statement`.
- Integrated `.github/` directories (pull templates, bug forms, actions workflows).
- Introduced path-prefixing compilation rules to support nested folders: `/pages/`, `/pages/blog/`, `/pages/projects/`.

### Changed
- Reorganized site assets into `/assets/css/`, `/assets/js/`, `/assets/images/`.
- Tweaked visual grids to remove the AI-generated aesthetic (added asymmetrical columns, custom chips).

## [1.0.0] - 2026-05-15
- Initial release featuring the local compile script and 35 foundational HTML pages.
