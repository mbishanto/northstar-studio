# Northstar Studio Website

This project is a modern, fully responsive website built with plain HTML, CSS, and JavaScript.

## Structure
- index.html — Homepage with hero, about highlights, services, portfolio, testimonials, contact form, and footer.
- about.html — About page with studio story and design approach.
- services.html — Services page highlighting available offerings.
- contact.html — Contact page with a project inquiry form.
- css/style.css — All visual styling, layout, responsiveness, and animation rules.
- js/script.js — Mobile navigation toggle, scroll reveal animations, footer year, and simple form interaction.
- images/ — SVG illustrations and gallery assets used across the pages.

## Run Locally
Open index.html in your browser, or serve the folder with a simple local web server.

## Notes
The site uses no external frameworks and is designed to be easy to customize.
